Generated by `python scripts/run.py sources.catalogue` from `src/dgt_stats/catalogue.py`; do not edit by hand.

Each table's sources are the data its values are computed from; the stage is the one `python scripts/run.py <stage>` runs to write it. Tables linked from a page are published on the site as downloads; the others stand behind a document, a figure or a check. The map of all sections is [`docs/catalogue.md`](../../../docs/catalogue.md).

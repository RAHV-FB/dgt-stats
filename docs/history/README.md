# History: the audit trail of the 2026 rebuild

These documents record how the study was audited and rebuilt in September and October 2026. Each
describes the repository at a named commit, so the figures, file names, module paths and table
names they quote are those of that commit: many have since changed (the tables were renamed and
moved into section folders, and the code into section packages, in the reorganisation that
followed). Their links have been kept working, but their text has not been updated, and nothing
here should be cited as a current result. The current results are in
[`reports/tables/`](../../reports/tables), on the site, and in the documents listed in
[`docs/README.md`](../README.md).

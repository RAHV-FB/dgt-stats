# Data analytics plan

Plan date: 2026-09-18. This plan follows the audit in [`data_inventory.md`](data_inventory.md) and
replaces the open-ended research tracks in the README with work that the files in hand can actually
support. It is deliberately modest: everything is done in Python with `pandas`, `statsmodels` and
`matplotlib`, and the only front end is a static HTML/CSS site generated by a script.

## 1. Scope decisions

**Keep.** Trends, seasonality, severity by road and environment context, geographic rates with proper
denominators, vulnerable road users, heavy vehicles per vehicle-km for 2022, older road users, and one
monthly-resolution policy evaluation.

**Drop until vehicle and person microdata are added.** Alcohol, drugs, distraction, fatigue, protective
equipment, driver age and sex, and any factor interaction such as alcohol × speed. The crash-level file
has none of these fields. The README and `methodology.md` sections that promise them should be marked as
"requires person-level data" rather than deleted.

**Reframe.** Speed becomes a descriptive chapter based on the DGT speed report and the 2024 infraction
table, not a modelling target. Campaign evaluation becomes a monthly interrupted time series on the
1993–2024 series, not a daily before/after study.

**Constraints.** Python only, simple methods, real deliverables. No dashboards, no
JavaScript frameworks, no machine learning before a defensible descriptive and regression baseline exists.

## 2. Analytical questions and how each is answered

| # | Question | Data | Method | Output |
|---|---|---|---|---|
| Q1 | How have injury crashes, deaths and hospitalisations evolved since 1993, and what did 2020 do to the trend? | series workbook (`Acc_Vict`, `Vict_I-U`, `Tasas_Acc_Vic`, monthly sheets) | line charts, indexed series, rates per 10,000 vehicles and per 100,000 population | trend page |
| Q2 | When do crashes and fatal crashes happen? | microdata 2016–2024 | hour × weekday heatmaps, monthly seasonality, night share, urban vs interurban | time-patterns page |
| Q3 | Given that a crash occurred, what makes it fatal or serious? | microdata | logistic regression: `fatal ~ zone + road_type + crash_type + lighting + weather + surface + junction + alignment + hour_band + weekday + year`; same for `serious` | severity page with odds ratios and 95% CIs |
| Q4 | Which provinces have high crash and death rates once exposure is considered? | 2024 tables, series province sheets, driver census 2023–2025, INE population (to be added) | rates per 100,000 population and per 10,000 licensed drivers, with Poisson CIs; ranking tables and bar charts | geography page |
| Q5 | How are deaths distributed across road-user types and how is that changing? | `TOT_*_MU30DF` columns, series `Cond_*` and `Pea_Vic` sheets | stacked shares by year, urban vs interurban, motorcycle and VMP trends | vulnerable-users page |
| Q6 | How dangerous are heavy vehicles and buses per kilometre driven? | 2022 microdata occupant deaths, `TABLA 2.3` involvement (2024), `Media_km_...` fleet × mean km | deaths per billion vehicle-km by vehicle type for 2022, with explicit caveat that involvement is only available for 2024 | heavy-vehicles page |
| Q7 | Are older road users at higher risk, and is that changing? | series `Vict_ED_*` sheets, DGT older-users report, INE population by age (to be added) | deaths per million by age band 2014–2024; replicate the DGT 47.8 vs 34.4 figure | older-users page |
| Q8 | Did a major policy change coincide with a measurable break in monthly deaths? | series `M_I-U_Meses` 1993–2024 | interrupted time series: Poisson or negative-binomial regression with linear trend, month dummies, level and slope change at the intervention; pre-trend plot | policy page |
| Q9 | How large is the speed factor and where does it concentrate? | DGT speed report, `TABLA 6.1.I/U` | descriptive tables only, with the report's exclusions stated (no Cataluña or País Vasco) | speed page |

Policy candidates for Q8, in order of preference:

1. Points-based licence, 1 July 2006: long pre and post windows, well documented, large effect expected.
2. Speed limit on conventional roads reduced from 100 to 90 km/h, 29 January 2019: clean pre-period,
   but the post-period runs into 2020, so the model must include a pandemic indicator or stop at
   February 2020.
3. Urban 30 km/h default, 11 May 2021: only use with the urban fatality series and a pandemic control,
   and report it as exploratory.

## 3. Pipeline

Everything below is plain Python modules in `src/dgt_stats/` with thin scripts in `scripts/`.

```text
data/raw/**  (xlsx, txt, pdf)
   │  scripts/ingest.py           (once; ~3 min for all microdata years)
   ▼
data/interim/*.parquet            harmonised names and types, original codes kept
   │  scripts/build_tables.py     (seconds)
   ▼
data/processed/*.parquet          decoded labels, derived fields, analysis tables
   │  scripts/analyse.py          (fits models, writes CSV results and SVG charts)
   ▼
reports/tables/*.csv, reports/figures/*.svg
   │  scripts/build_site.py
   ▼
site/*.html + site/style.css      static site, publishable with GitHub Pages
```

### Modules

| Module | Responsibility |
|---|---|
| `paths.py` | already exists; add `SITE_DIR` |
| `io_microdata.py` | read one year with `openpyxl` read-only mode, rename `SECUENCIAL`, add missing `TOT_VMP_MU30DF`, cast types, write Parquet |
| `io_tables.py` | read named sheets of the series and 2024 tables into tidy long frames |
| `io_exposure.py` | read census text files (strip padding, handle BOM, map `V/M`), the census workbook and the km workbooks |
| `codes.py` | load the dictionary workbook once and expose `decode(column, code)`; keep `999`, `998`, unknown and null as separate labels |
| `derive.py` | `fatal`, `serious`, `hour_band`, `road_group`, `night`, `n_vulnerable_deaths`, `year` |
| `validate.py` | reconciliation against the yearbook, key uniqueness, code domains, per-year missingness profile |
| `rates.py` | rate and Poisson/Wilson confidence-interval helpers |
| `models.py` | the logistic severity model and the ITS count model, returning tidy coefficient tables |
| `plots.py` | matplotlib defaults, one function per chart type, always writes SVG |
| `site.py` | render pages from a small string-template layout, no external template engine required |

### Derived fields

| Field | Definition |
|---|---|
| `fatal` | `TOTAL_MU30DF > 0` |
| `serious` | `TOTAL_MU30DF > 0 or TOTAL_HG30DF > 0` |
| `road_group` | motorway (`TIPO_VIA` 1–2), dual carriageway (3, 5), conventional (4, 6), urban street (9), service/ramp/track/other (7, 8, 10–14) |
| `hour_band` | 0–6, 7–9, 10–13, 14–16, 17–19, 20–23 |
| `night` | `CONDICION_ILUMINACION in {4, 5, 6}` |
| `weekend` | `DIA_SEMANA in {6, 7}` or Friday from 20:00 |
| `status_*` | for each condition column a companion label: observed / unknown / not specified / not applicable |

### Validation gates (tests in `tests/`)

1. Row count per year equals `Acc_Vict` total.
2. Sum of 30-day deaths, hospitalised and non-hospitalised per year equals `Vict_I-U`.
3. 2024 province and month totals equal `TABLA 1.1` and `TABLA 3.1`.
4. `(ANYO, ID_ACCIDENTE)` unique.
5. Every code in every categorical column exists in the dictionary or is one of the documented missing
   states; new codes fail the test so drift is noticed.
6. Census file totals equal the "Censo TOTAL" of the corresponding published table where a year overlaps.

## 4. Site

- Generated entirely by `scripts/build_site.py` into `site/`; committed output can be served from
  GitHub Pages without a build step.
- One `index.html` with the headline numbers and links, one page per question in section 2, and a
  `data.html` page that reproduces the inventory and validation results.
- Charts are SVG files produced by matplotlib, embedded with `<img>`; tables are plain `<table>` elements
  written from pandas with `to_html`.
- One `style.css` (readable widths, system fonts, light and dark colour scheme via
  `prefers-color-scheme`). No JavaScript.
- Every chart and table carries: source file, year range, definition of the outcome (24 h or 30 day),
  denominator, and sample size.

Phases 2 through 4 are the core portfolio result. Phases 5 to 7 add depth but depend on external
additions or carry stronger caveats.

## 8. Reporting rules that apply to every output

- State whether a count is 24-hour or 30-day. Never mix them in one chart.
- Report rates with the denominator and its year; never present crash counts as risk.
- Show unknown, not specified and not applicable as their own categories in every distribution.
- Give confidence intervals and n for every rate and coefficient.
- Label the DGT speed report figures as excluding Cataluña and País Vasco.
- Call model results associations; reserve causal wording for the ITS case study and only with the
  pre-trend and sensitivity checks shown.
